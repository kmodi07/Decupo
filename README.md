# Decupo

Decupo is an AI mission platform: describe a goal, review the plan and budget, let specialist agents execute approved steps, and monitor real progress.

**Status:** This repository is being initialized. The earlier 8-page website is a separate static prototype; it has not been deployed or connected to live agents. No product billing, account automation, or production deployment is configured here.

**Deployment policy:** Never modify www.decupo.com, DNS, customer data, billing, or existing services without an approved migration and backup plan.

See the upcoming setup pull request for the Claude Code team, real GitHub agent workflow, launch scope and usage instructions.
