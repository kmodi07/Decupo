# Mission execution
1. Turn the user's outcome into measurable deliverables, constraints and budget.
2. Decompose independent work into non-overlapping agent file ownership.
3. Run the smallest sufficient workforce; never fabricate agent work.
4. Use actual commands, file changes, logs and tests as proof.
5. Pause for permission before sending, paying, posting, logging into private services, or deploying.
6. Report each task as queued, working, done, failed or blocked with evidence.
7. Prefer a reviewed pull request over direct production changes.
